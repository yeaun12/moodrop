# 무드랍 · moodrop.

사진·문구·스티커로 오늘의 분위기를 한 장에 담는 카드 편집기입니다. 오렌지·크림·먹색의 무드 편집숍 디자인을 적용했습니다.

## 사용

index.html과 같은 폴더의 모든 파일 및 assets 폴더를 함께 정적 호스팅합니다. 서버나 API 키는 필요 없습니다.

- 왼쪽: 예시 카드 6종, 사진 넣기, 문구 3종, 스티커 12종, 배경 5종
- 중앙: 드래그 이동, 모서리 크기 조절, 위쪽 손잡이 회전
- 오른쪽: 문구·사진·스티커 속성 및 레이어 순서·잠금·숨김
- Ctrl/Cmd+Z: 실행 취소, Ctrl/Cmd+Shift+Z 또는 Ctrl/Cmd+Y: 다시 실행
- 방향키: 요소 이동, Shift+방향키: 크게 이동
- Shift+회전: 15도씩, Shift+크기 조절: 비율 유지
- 문구 더블클릭: 문구 입력란으로 이동
- PNG/JPEG 다운로드는 선택 테두리가 포함되지 않은 동일 렌더링 캔버스를 사용

레이어는 최대 40개, 템플릿은 최대 30개입니다. 문구는 레이어당 2,000자, 사진은 PNG/JPEG·10MB·2,000만 화소 이내입니다. 사진은 최대 변 1600px로 재인코딩하며 원본 EXIF·GPS를 복사하지 않습니다.

## 저장

현재 카드는 이 브라우저의 IndexedDB에 자동 저장됩니다. 내 템플릿에서 카드에 이름을 붙여 여러 개를 보관·수정·삭제할 수 있습니다. 브라우저 저장은 기기·도메인별이며 동기화가 아닙니다. JSON을 내려받아 백업하세요.

JSON version 2를 내보내고, version 1 및 2를 가져올 수 있습니다. 전체 스키마와 이미지를 먼저 검증한 후 한 번의 저장 트랜잭션으로 반영합니다. 동일 ID는 백업 내용으로 복원하고 다른 기존 항목은 유지합니다. 실패 시 목록과 현재 편집 내용이 유지됩니다.

## 원래 버전

기존 편집기는 같은 사이트의 classic/ 경로에서 보존됩니다. 원래 버전의 브라우저 저장값도 변경하지 않습니다. 예전 JSON을 가져오면 새 레이어 구조로 변환됩니다. V1의 단일 문구·배경 구성은 구조가 달라서 새로운 렌더링 결과가 픽셀 단위로 동일하지는 않습니다.

## 소스

- engine.js: 레이어, 검증, 그리기, 프레임, 템플릿, 좌표 판정
- editor.js: 실제 화면 이벤트, 포인터 조작, 실행 취소, IndexedDB, JSON
- core.js: 이전 버전 JSON 검증·이관에 사용하는 기존 모듈
- style.css, index.html: 반응형 편집 화면

## 사진·글꼴 권한

assets/cafe.jpg는 이 작업에서 생성한 예시 사진입니다. AI 보조 생성 이미지이며 실제 촬영 사진이나 학생 직접 촬영으로 표시하지 않습니다. 외부 사진을 재사용하지 않았습니다. 자세한 생성 프롬프트는 ASSET-CREDITS.md에 기록되어 있습니다.

CardSans.otf: Noto Sans CJK KR Bold 한글·라틴 서브셋. SIL OFL 1.1 (FONT-LICENSE.txt).
Hand.woff: Single Day. SIL OFL 1.1 (Hand-LICENSE.txt).
Serif.woff: Noto Serif KR 700 인스턴스·한글·라틴 서브셋. SIL OFL 1.1 (Serif-LICENSE.txt).

## 검증 범위

핵심 렌더링·입력 검증·JSON 변환과 실제 editor.js 이벤트를 Node Canvas 및 DOM/IndexedDB 모의 환경에서 검사했습니다. 실제 브라우저의 터치 동작, 다운로드 창, 새로고침, 반응형 화면에 대한 검사는 아직 수행하지 않았습니다. 이는 모의 검사와 구분해야 합니다.

## 무드랍 화면 업데이트

밝은 도구 메뉴, 오렌지 선택 표시, 카드 썸네일 템플릿 갤러리, 일상 문구 예시 카드 6종. 모바일은 하단 메뉴로 꾸미기 패널을 열고 접으며, 요소 편집 버튼으로 속성을 엽니다. 실제 모바일 화면의 시각 검증은 미실시입니다.
