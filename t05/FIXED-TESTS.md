# T05 고정 검사 H01–H10

이 기준은 A 시작 전 대화에서 확정해 사용자가 과제 화면에 입력하도록 제공한 내용이다. 저장소 파일은 그 기준을 옮긴 것이다. 실제 과제 화면의 입력 내용·기록 시각은 사용자가 보관하며, 이 파일이 플랫폼 기록을 대체하지 않는다.

## 공통 조건
각 검사는 저장된 작업이 없는 독립적인 브라우저 환경에서 시작한다. 사진과 글꼴 로딩이 끝난 기본 카드 ‘오늘 좀 좋음’의 첫 번째 문구 레이어를 사용한다.
초기 문구는 “오늘 좀\n좋음.”(\n은 줄바꿈), 색상은 #e95b25, 위치는 X=48·Y=20이다.
문구 입력은 전체 선택 후 붙여넣고 입력란 밖을 클릭해 완료한다. 위치 변경은 위치 입력란의 X값만 변경한다. 지정하지 않은 카드 속성은 유지한다.

## 공통 편집 순서
- S0: 초기 상태.
- S1: 문구를 “오늘도 좋음”으로 변경 완료.
- S2: S1에서 색상을 #cf3934로 변경.
- S3: S2에서 X를 60으로 변경 완료. Y는 20 유지.
- 각 S는 해당 편집이 끝난 직후의 기록을 뜻한다.

| ID | 입력 | 기대값 |
|---|---|---|
| H01 | 새 편집기를 열고 편집 기록 목록 확인 | ‘초기 상태’ 기록 1개가 있고 현재 기록으로 강조된다. |
| H02 | S0에서 S1 작업 수행 | 문구 변경 기록이 추가되고 현재 기록으로 강조된다. 카드 문구는 “오늘도 좋음”이다. |
| H03 | S2까지 편집한 뒤 S1 기록 클릭 | 문구는 “오늘도 좋음”, 색상은 #e95b25로 복원되고 S1이 강조된다. |
| H04 | S3까지 편집한 뒤 S2 기록 클릭 | X=48·Y=20으로 복원된다. 문구는 “오늘도 좋음”, 색상은 #cf3934이며 S2가 강조된다. |
| H05 | S3까지 편집한 뒤 S0 기록 클릭 | 문구는 “오늘 좀\n좋음.”, 색상은 #e95b25, 위치는 X=48·Y=20으로 복원되고 S0이 강조된다. |
| H06 | S3까지 편집한 뒤 S1 클릭 → S3 클릭 | 이후 기록이 유지되어 S3을 다시 선택할 수 있다. 최종 문구는 “오늘도 좋음”, 색상은 #cf3934, 위치는 X=60·Y=20이며 S3이 강조된다. |
| H07 | S3까지 편집한 뒤 현재 기록 S3을 다시 클릭 | 카드 전체 상태, 기록 개수, 현재 기록이 모두 변하지 않는다. |
| H08 | S3까지 편집 → S1 클릭 → 문구를 “새로운 시작”으로 변경 완료 | 기존 S2·S3 기록은 삭제되고 새 문구 변경 기록이 현재 기록으로 추가된다. 문구는 “새로운 시작”, 색상은 #e95b25, 위치는 X=48·Y=20이다. 다시 실행 버튼은 비활성화된다. |
| H09 | S3까지 편집 → 실행 취소 버튼 클릭 → 다시 실행 버튼 클릭 | 실행 취소 후 S2가 강조되고 X=48이다. 다시 실행 후 S3이 강조되고 X=60이다. 두 상태 모두 문구는 “오늘도 좋음”, 색상은 #cf3934, Y=20이다. |
| H10 | S3까지 편집 → S1 기록 클릭 → PNG 다운로드 | 정상적으로 열리는 1080×1350 PNG가 생성된다. 문구 “오늘도 좋음”, 색상 #e95b25, 위치 X=48·Y=20의 복원된 미리보기와 이미지 내용이 일치하며 선택 테두리는 포함되지 않는다. |

## 실행
Node.js 20 이상과 npm, Python 3, Git을 사용한다.

```sh
npm ci
npx playwright install chromium
npm run test:t05
```

검사기가 임시 로컬 HTTP 서버를 직접 열고 닫는다. 결과는 `t05/evidence/latest/results.json`, 화면은 H01.png~H10.png, 다운로드 결과는 H10-download.png에 남는다. FAIL 또는 BLOCKED가 있으면 종료 코드 1이며, A의 계획된 미완성 상태에서는 정상적인 보고 방식이다.

기존 Chromium을 쓰려면 `CHROMIUM_EXECUTABLE`을 해당 실행 파일의 절대 경로로 지정한다. 브라우저 설치 실패는 검사 통과가 아니다. 10개를 모두 실행한 회차 중 FAIL이 하나 이상이면 오류 회차 1회로 센다. 준비 작업의 구문 검사나 브라우저 설치 재시도는 고정 검사 실행 회차가 아니다.

H10은 복원 전에 S1의 실제 캔버스 픽셀을 저장하고 다운로드 PNG를 디코딩하여 비교한다. 변경 후 상태만 자기 자신과 비교하지 않는다. 입력·기대값은 이 문서 및 fixed-tests.json이 기준이다. 자동화 선택자는 `.history-entry`, `data-history-id`, `aria-current="step"`을 사용한다.
