# A와 B의 공통 최초 요청

아래 본문은 A 작업 시작 전에 과제 화면에 입력하도록 확정한 요청이다. B에는 이 파일을 포함하는 저장소와 동일한 인수인계 문서만 전달한다.

무드랍에 ‘편집 기록을 클릭하면 해당 시점으로 복원하는 기능’을 추가하세요.

편집 기록 목록에 초기 상태와 각 편집 완료 후 상태를 표시하고, 현재 기록을 강조하세요. 과거 기록을 클릭하면 카드 전체를 해당 상태로 복원하며, 이후 기록도 새 편집 전까지 다시 선택할 수 있어야 합니다. 과거 상태에서 새로 편집하면 이후 기록을 삭제하고 새 기록을 추가하세요. 기존 실행 취소·다시 실행과 기록 목록은 같은 현재 상태를 가리켜야 합니다. 복원 후 PNG 다운로드 결과도 미리보기와 일치해야 합니다.

기록은 현재 편집 세션에서만 유지합니다. 새로고침을 넘는 기록 보존은 이번 범위에서 제외합니다. 기존 디자인, 템플릿 저장·불러오기, JSON 백업·복원, 이미지 내보내기는 유지하세요.

첨부된 고정 검사 H01~H10을 사용하며 검사 삭제·완화·기대값 변경은 금지합니다. AI별 시간 상한은 45분, 사용자 작업 요청 메시지는 최대 10회입니다. 최초 구현 요청을 1회로 세고, 실제 작업 시작부터 종료·인수인계까지의 시간과 요청 수를 기록하세요. 내부 도구 호출은 사용자 요청 수와 구분합니다.

AI A는 기록 저장 구조와 목록 표시를 구현한 뒤, 클릭 복원과 기존 실행 취소·다시 실행 연동을 B의 남은 작업으로 남기고 중단하세요. AI B는 저장소와 인수인계 문서만으로 남은 기능을 완성하세요. 각 AI는 종료 전에 같은 검사 10개를 실행하고 실제 결과를 기록하세요. 실행하지 못한 검사는 미실행으로 표시하고 통과로 계산하지 마세요.

오류 수는 고정 검사 실행 회차 중 하나 이상의 FAIL이 나온 회차 수로 계산하세요. 시작·종료 소스 버전과 검사 결과를 보존하고, 인수인계에는 목표·현재 상태·실행 명령·통과 검사·남은 문제·다음 행동·건드리지 말 것의 7항목을 포함하세요.
